Bundle ID org.verdepitch.codexfolio, version 1.2.4. On iPhone or iPad running iOS or iPadOS 17.4 or later, the app opens directly to Learn with the full bundled course, zero progress and reminders off. No account or onboarding is required. The course, practice, exams and progress work offline.

Open the daily law from Learn, bookmark it, mark it as studied and try its practice decision. Check the bookmark under Saved laws in Rulebook. In Practice, answer a question incorrectly and confirm it appears in the mistakes review. Answer it correctly to clear it. Start a seasonal exam block, advance after answering and reopen the block to verify that it resumes at the next unanswered question. Submit to see the score and answer review. To test the certificate in My course, pass all three blocks in the current season with at least 80% in each. Enter a name, generate the PDF, preview it and test the system Share action. The certificate is a personal learning record with a non-endorsement notice.

In Rulebook, import an unlocked, non-empty PDF smaller than 40 MiB through Files and check search and contents in the PDFKit reader. The imported copy opens offline. The external IFAB links require internet access. In Settings, export and reimport a course progress JSON file to verify the local merge. Files access is scoped to the selected file. Progress is stored locally. Settings mentions iCloud, and course transfer uses JSON files. iCloud sync is unimplemented.

Enable a reminder in Settings to trigger the notification permission request for alerts, sounds and badges. Delivery uses local notifications despite the declared push entitlement and remote notification background mode. The WidgetKit extension reads shared app-group data and links to a law or My course. The refereefolio URL scheme can open Practice or a specific law.
